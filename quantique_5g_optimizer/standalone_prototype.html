1. QUBO Cost Hamiltonian Formulation

The resource allocation problem is mapped to a Quadratic Unconstrained Binary Optimization (QUBO) problem over binary variables $x_{t,f} \in \{0, 1\}$, where $x_{t,f} = 1$ denotes base station $t$ assigned to subband $f$ with power level $p_{t}$:

$$\min_{\mathbf{x}} H_C(\mathbf{x}) = -\alpha \sum_{u=1}^{U} \text{SINR}_u(\mathbf{x}) + \beta \sum_{u, t \neq s(u)} I_{u, t}(\mathbf{x}) + \gamma \sum_{t=1}^{T} P_t(\mathbf{x}) + \lambda \sum_{t=1}^{T} \left( \sum_{f=1}^{F} x_{t,f} - 1 \right)^2$$
  • SINR Maximization ($\alpha = 1.0$): Rewards configurations providing high direct signal-to-noise ratio.
  • Interference Penalty ($\beta = 2.5$): Heavily penalizes co-channel transmissions whose beam sidelobes illuminate neighboring active cells.
  • RF Power Conservation ($\gamma = 0.5$): Incentivizes minimal base station power backoff necessary to meet target QCI.
  • Single-Subband Constraint ($\lambda = 10.0$): Quadratic penalty enforcing exactly one subband per base station transceiver.

2. QAOA Variational Quantum Eigensolver Workflow

The Quantum Approximate Optimization Algorithm (QAOA) prepares a parameterized $n$-qubit quantum state via alternating unitary operators:

$$|\psi(\boldsymbol{\gamma}, \boldsymbol{\beta})\rangle = \prod_{l=1}^{p} e^{-i \beta_l H_M} e^{-i \gamma_l H_C} |+\rangle^{\otimes n}$$
  • Initial State: Equal superposition state $|+\rangle^{\otimes n} = H^{\otimes n} |0\rangle^{\otimes n}$.
  • Cost Unitary $U(C, \gamma_l) = e^{-i \gamma_l H_C}$ : Encodes the problem QUBO matrix into diagonal phase shifts.
  • Mixer Unitary $U(M, \beta_l) = e^{-i \beta_l H_M}$ : Non-commuting transverse field driver $H_M = \sum_{j=1}^n X_j$ enabling quantum state exploration.
  • Classical Optimizer Loop: Classical COBYLA / SPSA algorithm iteratively updates variational parameters $(\boldsymbol{\gamma}, \boldsymbol{\beta})$ to minimize $\langle \psi | H_C | \psi \rangle$.
